# 软件与网络安全标准枢纽

## 应用要点

- 软件安全分级（IEC 62304 Class A/B/C）决定文档与验证深度；Class C（危及生命的支持/驱动）要求最高。
- 网络安全：欧盟 MDR 下 PEMS（可编程电子医疗器械系统）须有网络安全文件（MDCG 2019-16），并纳入 ISO 14971 风险管理。
- SaMD：按 IMDRF 框架分类，关注算法变更管理与临床评价。
