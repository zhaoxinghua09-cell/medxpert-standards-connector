## 按区域 / 归口方速查

- **国际通用（ISO/IEC）**：ISO 13485、ISO 14971、ISO 10993、IEC 62304、IEC 60601、ISO 14644
- **中国（GB / YY / YY-T）**：GB/T 42061、GB/T 42062、GB/T 16886、GB/T 13810、GB 4234、YY 0033、YY/T 1752、GB 9706、GB 50073
- **美国（ASTM / FDA / 21 CFR）**：ASTM F138/F139/F2063、21 CFR 820 (QMSR)、FDA 10993-1 指南
- **欧盟（EN / MDCG）**：EN ISO 13485、MDCG 2019-15、MDCG 2019-16、MDCG 2021-9
- **行业组织（ASTM F04 植入物材料）**：ASTM F138、F139、F2063、F3127、F67

## 使用提示

- 检索标准号、中文名、材料牌号、主题词均可用 `search_standards`。
- 按区域筛选用 `standards_by_region`（中国 / 国际 / 美国 / 欧盟 / 日本 / ISO / ASTM / IEC）。
- 标准正文版权归各标准组织所有；正式采用请以官方发布版本为准。
