# 设计开发标准枢纽

> 医疗器械设计开发控制与可用性 / 人因工程标准。连接「用户需求 → 产品」的主线，须形成设计历史文件（DHF）。

## 应用要点

- 设计开发控制是各国技术文档的必备章节；设计输入须可验证，设计验证（V&V）对应预期用途。
- 可用性工程（IEC 62366）在设计阶段介入，识别使用错误并控制；与风险管理（ISO 14971）联动。
- 设计转移（7.5.6 过程确认）确保生产再现性；设计变更须评审、验证/确认、批准，纳入变更控制。
